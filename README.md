### 🧠 DocMind AI — RAG-Powered Document Intelligence SaaS &nbsp;·&nbsp; [![Live](https://img.shields.io/badge/●%20LIVE-00d4aa?style=flat-square&logoColor=white)](https://docmind.vaultfs.in) &nbsp;·&nbsp; [![GitHub](https://img.shields.io/badge/⌥%20GITHUB-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/kanhaiyaray/Docmind-Ai) 

> *Most "chat with PDF" projects are a weekend wrapper around a chat API. Nobody builds the production layer underneath — grounded retrieval, page-level citations, and real session security. DocMind does.*

A full-stack RAG (Retrieval-Augmented Generation) SaaS that turns static PDFs into a conversational, cited knowledge base — with the auth, admin tooling, and audit trail of a real product, not a demo.

- **RAG Pipeline:** PDF text extraction → semantic chunking → OpenAI embeddings → MongoDB Atlas Vector Search for similarity search → GPT-5.6 Luna answer generation with page-level citations
- **Study Tools:** Single- and multi-document conversational chat, AI-generated quizzes/flashcards, and document comparison surfacing shared themes and contradictions
- **Auth & Admin:** JWT + HTTP-only cookies, CSRF double-submit protection, IP-based rate limiting, and an admin dashboard for cross-user document/activity oversight — all shipped solo

`React` `Vite` `Node.js` `Express` `MongoDB Atlas Vector Search` `OpenAI API` `JWT` `Tailwind CSS`

### 🗄️ VaultFS — Enterprise File Management &nbsp;·&nbsp; [![Live](https://img.shields.io/badge/●%20LIVE-00d4aa?style=flat-square&logoColor=white)](https://vaultfs.in) &nbsp;·&nbsp; [![GitHub](https://img.shields.io/badge/⌥%20GITHUB-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/kanhaiyaray/VaultFS-Enterprise-File-Management-System) 

> *Self-hosting file storage is either expensive (S3) or insecure (shared drives). VaultFS solves both.*

Production-ready enterprise file management platform with enterprise-level security and role management — compliance features rarely built at fresher level.

### 💬 NexChat — Invite-Only Real-Time Chat &nbsp;·&nbsp; [![Live](https://img.shields.io/badge/●%20LIVE-00d4aa?style=flat-square&logoColor=white)](https://nexchat.vaultfs.in) &nbsp;·&nbsp; [![GitHub](https://img.shields.io/badge/⌥%20GITHUB-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/kanhaiyaray/NexChat) 

> *Most chat apps are open by default. NexChat is zero-trust — you need a token to enter a room.*

Invite-only real-time chat platform with private rooms, multi-user sessions, and rich multimedia support. 1000+ messages handled in production.

- **Security:** Zero-trust room model — no invite token, no entry; no public directories, no discovery; a signed UUID token is the sole entry point
- **Features:** Text, voice notes, images, reactions, edits, typing indicators, and read receipts via Intersection Observer (zero scroll listeners, zero layout thrash)
- **Performance:** Optimized MongoDB indexing and caching, cutting dashboard load from 5–8s to 1–2s (4–5x) · deployed on Vercel/Render with HTTPS, CORS, OAuth, and rate-limited APIs

`React` `Node.js` `Express` `Socket.IO` `MongoDB` `Cloudinary` `Clerk`
